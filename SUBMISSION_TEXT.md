# Coursera submission — listen to twenty three

## Project description

**listen to twenty three** is a responsive music portfolio that brings together three featured tracks — “IG MODEL,” “Queen St,” and “The Highest ft. Stopthis” — with a consistent visual identity. The site includes three connected pages: Home, Music & Visuals, and About. Four original SVG artworks are stored locally in the project, so the artwork does not depend on a third-party image host.

The website is built from scratch using semantic HTML, a custom CSS stylesheet and JavaScript. Its layout adapts to mobile, tablet and desktop screens. The visual system uses a dark, editorial palette with a high-contrast lime accent, large typographic headings, generous spacing and responsive artwork cards.

## Four enhancements

1. **Custom JavaScript search and filters:** the Music & Visuals page can be searched by text and filtered to show all items, tracks only or the visual study. A live result count, clear-search button and no-results/reset state support the interaction.
2. **Manual artwork carousel:** the Home page has previous/next buttons and direct slide controls. The carousel does not autoplay, and its current slide is announced to assistive technology.
3. **Light/dark theme switch:** visitors can switch the site's colour palette. The preference is saved when browser storage is available.
4. **Accessibility enhancements:** each page includes a skip link, semantic page landmarks, descriptive image alternatives, labelled controls, visible keyboard focus, ARIA state/live updates and reduced-motion support.

The site also includes responsive layout changes for phone, tablet and larger screens, plus a flex-based footer layout for consistent page structure.
